SMART CANTEEN - PROJECT REQUIREMENTS

1. MongoDB Community Server
   Used for storing student details, admin information,
   food menu, and order records.

2. Node.js
   Required to execute the backend application.

3. npm
   Used for installing and managing project dependencies.

4. Web Browser
   Required to access the student and admin dashboards.

   BACKEND CONFIGURATION

1. Navigate to the server directory.
2. Install the required Node.js packages.
3. Configure the MongoDB connection in the .env file.
4. Initialize the database using the seed script.
5. Start the backend server.

Commands:

cd server
npm install
npm run seed
npm start
