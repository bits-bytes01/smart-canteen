SMART CANTEEN - PROJECT REQUIREMENTS

1. MongoDB Community Server
   Used for storing student details, admin information,
   food menu, and order records.

2. Node.js
   Required to execute the backend application.

3. npm
   Used for installing and managing project dependencies.

4. Web Browser
   Required to access the student and admin dashboards.

--install mongodb community

--install node.js

--open command prompt in the folder server

--enter npm install

--then, npm run seed

--then, npm start

--create account and login

--for admin dashboard url-http://localhost:3000/admin

--for admin password and phoneno or email check .env file
